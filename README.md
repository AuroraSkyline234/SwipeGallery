# Листай / SwipeGallery

Приложение для iPhone с iOS 17+: фото и видео из галереи по очереди.

- Влево — оставить, вправо — выбрать для удаления.
- Кнопка со стрелкой назад отменяет последний выбор.
- Решения сохраняются между запусками.
- Кнопка «Удалить выбранное» вызывает подтверждение iOS.
- При отмене удаления файлы и выбранный список сохраняются.
- Нет своего сервера, рекламы или загрузки вашей галереи в GitHub.

При полном доступе видна вся доступная PhotoKit медиатека, при ограниченном — только разрешённые файлы. Удаления в «Фото iCloud» синхронизируются между вашими устройствами.

## Бесплатная сборка с Windows

1. Откройте [Actions](https://github.com/AuroraSkyline234/SwipeGallery/actions/workflows/build.yml).
2. Выберите успешный запуск **Build iPhone app**.
3. Скачайте **SwipeGallery-iPhone** из Artifacts и распакуйте ZIP.
4. Установите `SwipeGallery.ipa` через **AltStore Classic** (не AltStore PAL).

[Официальная установка AltStore с Windows](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows).

IPA не подписан: AltStore подписывает его вашим Apple ID при установке. На бесплатном Apple ID подпись нужно обновлять каждые 7 дней. Для обновления используйте Refresh All в AltStore при доступном AltServer. Пароли и коды Apple ID вводите только в соответствующих приложениях и никогда не публикуйте в репозитории.

## Проверка на устройстве

Сначала используйте несколько ненужных тестовых фото и видео: проверьте оба свайпа, отмену, сохранение после перезапуска, отмену системного удаления и подтверждённое удаление. Затем проверьте видео и ограниченный доступ к галерее. Облачная компиляция проверяет сборку; поведение PhotoKit нужно проверять на iPhone.

## Сборка на Mac

Установите Xcode и XcodeGen, затем выполните `xcodegen generate`. Откройте сгенерированный проект, настройте подпись для своего устройства и запускайте приложение.
